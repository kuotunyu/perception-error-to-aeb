# nuPlan-derived addendum notice

The JSON files in `evidence/`, the registry `claims.yaml` and the values
restated in `results.md` are compact derived evidence from **nuPlan v1.1**.
They are computed from the per-token records of the v1.0.0 formal run, which
was created from Motional's dataset with nuPlan devkit commit
`e9241677997dd86bfc0bcd44817ab04fe631405b`.

They hold aggregates only: Shapley values, their differences and configuration
contrasts with bootstrap intervals, counts, Clopper-Pearson intervals and
distribution summaries. No scenario token, log name, scenario list, per-token
table, database, map, sensor media, point cloud, raw trajectory export, or
model artifact is included.
