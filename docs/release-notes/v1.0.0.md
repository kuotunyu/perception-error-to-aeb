# v1.0.0 發布說明

這個版本整理固定 nuPlan cohort 上的 deterministic AEB 研究證據、雙語首頁、可重現 SVG 圖表與預先固定選樣的衍生回放。

首頁同時呈現介入時間與 false/missed events，補上碰撞結果的煞車代價；
[研究卡](../experiment-card.md)集中說明設計、分母、比較方式與適用限制。
這些展示使用既有證據，沒有重跑模擬或修改 protocol。

## 已驗證的觀察

- 共同有效 cohort 的 `common_valid_tokens` = 344。<!-- claim: p3.evaluation.common_valid_tokens --> 各設定使用相同 token；scenario-replicates 不是獨立樣本。
- no AEB 的 `collisions` = 204。<!-- claim: p3.baseline.collisions.no_aeb -->
- oracle AEB 的 `collisions` = 39 <!-- claim: p3.baseline.collisions.oracle_aeb -->，並記錄 `contacts_not_at_fault` = 1095。<!-- claim: p3.baseline.contacts_not_at_fault.oracle_aeb -->
- full medium coalition 的 `collisions` = 0 <!-- claim: p3.coalition.collisions.coalition-dropout-localization_shape-latency-track_instability -->，另有 `contacts_not_at_fault` = 1150。<!-- claim: p3.coalition.contacts_not_at_fault.coalition-dropout-localization_shape-latency-track_instability --> 零個計入碰撞不等於零接觸、較佳感知或實車安全。
- Shapley collision game 中 localization/shape 的觀察平均貢獻為 `collision_indicator` = -0.027374031007751935。<!-- claim: p3.shapley.collision_indicator-values-localization_shape -->
- Shapley intervention-duration game 中同一 channel 的觀察平均貢獻為 `intervention_duration_s` = 4.0670219638242875。<!-- claim: p3.shapley.intervention_duration_s-values-localization_shape -->

兩個 Shapley estimand 的單位與尺度不同，不可相加、互相比較或視為顯著性。它們分解 full-minus-empty `coalition-none`；零嚴重度 tracker 仍從位置差分估計速度，不是 oracle。

`bicycle_or_vru` 的 `valid_tokens` = 44 <!-- claim: p3.family-interventions.bicycle_or_vru.oracle_aeb.valid_tokens -->，低於 protocol 的 `evaluation_per_family` = 100。<!-- claim: p3.family-interventions.evaluation_per_family --> 這只描述樣本不足，不是 efficacy claim，因此不對該 family 的介入率提出正式結論。

## 展示與重現

新增 `aeb-family-interventions/v1` 摘要與 strict schema。類別介入圖的分母是 scenario-replicates，事件率不是含事件情境的百分比，也沒有套用全體 bootstrap bounds。兩張 SVG 都由 evidence 產生且可逐位元重建。

每個 family 的回放 token 由 oracle AEB mean intervention duration 的 median-nearest 規則預先決定，再重建 oracle、empty coalition 與 full coalition 的 replicate zero。回放只有 scenario-local geometry、匿名 actor ID、狀態與時間，不含 sensor pixels、地圖、nuBoard log、native token 或 raw trajectory export。重建結果會與凍結 formal record 共有的碰撞、接觸、曝光與介入量測逐項核對；formal schema 沒有 final pose/speed，兩者只與 fresh simulator outcome 核對。

## 限制

requested maximum horizon 是 15 秒上限，實際執行可能因碰撞、路徑結束或資料結束而提前停止，因此曝光要逐設定閱讀。logged actors 不會對 ego 反應。接觸分類排除停止 ego，或位於 ego 後方且速度大小較大的物件；它不是 longitudinal closing-velocity test、完整 nuPlan 等價證明或法律責任判定。本版只測固定的一種 AEB policy；每 100 km 碰撞率為未提供。
